
# Intern Infobyte – Task 1: Sales Data Analysis

## Project Overview
This project focuses on analyzing the Sample Superstore dataset to identify sales trends, seasonal patterns, product performance, and business insights.

## Objective
To analyze sales data and understand business performance using Python and data visualization techniques.

## Dataset
Sample Superstore Dataset obtained from Kaggle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

## Project Activities
1. Dataset Loading
2. Data Exploration
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis
5. Sales Trend Analysis
6. Seasonal Analysis
7. Product Performance Analysis
8. Advanced Visualization and Dashboard Creation

## Interactive Dashboard
An interactive dashboard was developed using Streamlit to visualize:
- Overall sales and profit
- Monthly sales trends
- Category performance
- Regional sales distribution
- Top 10 products
- Discount and profit relationship

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn plotly streamlit
```

Run the dashboard:

```bash
streamlit run dashboard.py
```

## Project Outcome
The project provides an interactive approach to understanding sales performance and identifying business insights.
